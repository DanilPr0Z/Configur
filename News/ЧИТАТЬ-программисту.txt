ЗАПИСКА ПРОГРАММИСТУ — калькулятор «Обрамление проёма» (Cascate Porte)
=====================================================================

ЧТО ЭТО
-------
Готовый самодостаточный калькулятор стоимости обрамления проёма.
- cascate_calculator.html — вся страница целиком: HTML + CSS + JS вшиты внутрь (inline).
- schemes/ — папка с картинками схем моделей (25 шт). Файл обращается к ним
  по ОТНОСИТЕЛЬНОМУ пути "schemes/...", поэтому папка schemes должна лежать
  РЯДОМ с html-файлом (сохранить структуру как в архиве).

ЧТО НУЖНО СДЕЛАТЬ
-----------------
Разместить этот калькулятор на нашем сайте — отдельной страницей или встроенным
блоком (по договорённости с владельцем). Внешних зависимостей почти нет,
достаточно залить оба объекта (html + папку schemes) и сослаться на страницу.

ВАЖНО (не пропустить!)
----------------------
1. ФОРМА ЗАЯВКИ НИКУДА НЕ ОТПРАВЛЯЕТСЯ. Сейчас по нажатию показывается экран
   «Заявка отправлена», но данные не уходят. В коде это место помечено
   комментарием (искать по слову fetch, примерно строка 875):
      // Здесь можно добавить fetch() для отправки на сервер / email / Telegram
   Нужно подключить реальную отправку лида (email / Telegram-бот / CRM).
   Куда именно слать заявки — уточнить у владельца.

2. ЦЕНЫ И ФОРМУЛЫ ЗАШИТЫ ВНУТРИ html-файла (в JS). При изменении цен править
   значения прямо в файле. Исходник расчётов — приложенный Excel
   (Обрамление_проема_КАЛЬКУЛЯТОР_v3.xlsx), для сверки логики.

3. МЕЛОЧЬ: в <head> остался лишний тег Cloudflare
   <script ... src="/cdn-cgi/scripts/.../email-decode.min.js">
   Это артефакт от прошлого хостинга, на нашем сайте он просто не найдётся
   (безвредно). Можно удалить эту строку — чище.

4. Шрифт PT Sans подгружается с Google Fonts (внешняя ссылка в <head>).
   Если сайт должен работать без обращений наружу — надо положить шрифт локально.

ПРОВЕРКА, ЧТО ВСЁ НА МЕСТЕ
-------------------------
Открыть cascate_calculator.html двойным кликом — калькулятор должен считать
и показывать картинки схем. Если картинки не видны — значит папка schemes
лежит не рядом с файлом.
